## 4. Market evidence to build

Create and maintain a structured discovery register containing:

- organization and role interviewed;
- date;
- current workflow;
- pain frequency / severity;
- current tools / alternatives;
- procurement owner;
- security / data constraints;
- pilot interest;
- willingness-to-pay evidence;
- follow-up status.

Aggregate market claims only after enough interviews support them.

## 5. Scientific / performance evidence

### Available

- validation protocol and ledger architecture;
- evidence-boundary language;
- implemented analytical and forecasting workflows.

### Required before stronger claims

- frozen benchmark datasets;
- baseline models / workflows;
- reproducible evaluation runs;
- calibration metrics;
- precision / recall where applicable;
- temporal holdout / backtesting evidence;
- failure analysis;
- external or partner-domain review where feasible.

## 6. Security / governance diligence

Repository controls exist, but deployment-specific assurance remains separate.

Future diligence may require:

- threat model for the target deployment;
- DPIA / privacy analysis where applicable;
- penetration test or independent security assessment;
- incident-response procedure;
- access-control review;
- subprocessors / data-flow register;
- backup / recovery evidence;
- target-specific availability and recovery objectives.

## 7. Financial model

Not yet treated as validated evidence.

Before a priced institutional round, prepare:

- 24–36 month operating model;
- hiring plan;
- cloud / data / model-cost assumptions;
- sales-cycle assumptions;
- pilot-to-enterprise conversion assumptions;
- gross-margin model;
- scenario analysis;
- runway and use-of-funds model.

Every assumption should be labelled as assumption until supported by operating evidence.

## 9. Diligence red lines

Never claim or imply without evidence that AICIS has:

- customers or revenue;
- government / UN endorsement;
- validated national-security capability;
- independently proven humanitarian effectiveness;
- guaranteed forecasts;
- autonomous authority over consequential decisions;
- production deployments that have not occurred.

Investor readiness depends on making the real engineering strength easy to verify while keeping unproven claims visibly bounded.
