# Optimize AICIS Landing UI/UX

## Scope
- Refine the public landing page, prioritizing the 390px mobile first viewport while preserving the desktop experience.
- Keep the current dark enterprise identity, AICIS copy, live data, trust positioning, and existing actions.

## Changes
- Replace the overflowing mobile navigation with a compact brand row and accessible menu for secondary links.
- Tighten the opening layout and headline wrapping so the value proposition, actions, and start of the live map appear sooner.
- Improve text contrast, action hierarchy, touch target sizing, and small-screen spacing.
- Reflow the trust indicators and map legend to avoid clipping or cramped labels.
- Remove unsupported or misleading headline statistics from the public trust strip unless they are derived from live evidence.
- Preserve restrained motion and support reduced-motion preferences.

## Validation
- Check the public page at 390×710 and desktop widths for overflow, overlap, readability, and visible map attribution.
- Confirm navigation and both primary actions work.
- Confirm the preview build remains clean.
